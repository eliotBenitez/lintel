# Lintel

**Верхняя панель GNOME Shell в стиле macOS Tahoe, построенная поверх штатной панели, а не вместо неё.**

---

Lintel превращает верхнюю панель GNOME в строку меню по образцу macOS Tahoe. В ней
появляются системное меню, название активного приложения, отдельные меню Wi-Fi и
батареи, Центр управления и плавающий Центр уведомлений с виджетами.

Штатную панель GNOME (`Panel`) Lintel не заменяет: он переставляет её содержимое
и возвращает всё на место при отключении. Уведомления, специальные возможности,
геометрия рабочей области и значки других расширений продолжают работать.
**После отключения Lintel стандартная панель возвращается сразу, выходить из
сеанса не нужно.**

## Возможности

- **Системное меню.** Логотип слева (его можно сменить) открывает компактное
  меню: «Об этом компьютере», «Параметры», «Центр приложений», «Недавние объекты»,
  «Завершить принудительно», «Режим сна», «Перезагрузить», «Выключить»,
  «Заблокировать» и «Выйти». Все пункты используют системные действия GNOME и
  его диалоги подтверждения.
- **Название активного приложения.** Рядом с логотипом жирным шрифтом
  показывается название приложения в фокусе. При переключении через Alt+Tab
  оно меняется без мерцания.
- **Часы в стиле macOS.** Дата выводится в порядке, принятом в вашей локали, а
  цифры одинаковой ширины, так что панель не сдвигается каждую минуту. Настройки
  как в macOS: показ даты, дня недели, AM/PM и секунд.
- **Центр уведомлений.** Нажмите на часы или <kbd>Super</kbd>+<kbd>V</kbd>, и
  справа откроется плавающая колонка карточек. Внутри используется штатный
  список уведомлений GNOME, поэтому группировка, действия, закрытие и «Очистить»
  работают как обычно. Виджеты: Календарь, Ближайшие события, Погода, Экранное
  время, Система (процессор, память, сеть), Аккумулятор, Сейчас играет и Часы. В
  режиме «Изменить виджеты» их можно добавлять, удалять, переставлять и менять
  им размер.
- **Центр управления.** Всплывающее окно в раскладке Tahoe:
  - переключатели Wi-Fi, Bluetooth, «Фокусирование» («Не беспокоить») и тёмной
    темы
  - плитка AirDrop, которая открывает приложение для обмена файлами с
    устройствами поблизости (см. [Требования](#требования))
  - «Сейчас играет» (MPRIS)
  - ползунки яркости и громкости
  - кнопки утилит

  **«Настроить элементы управления»** меняет окно прямо на месте: элементы можно
  убирать, возвращать, переставлять и переключать между кругом и широкой
  капсулой. Там же можно добавить авиарежим, режим питания, ночной свет и
  слайдер микрофона — по умолчанию их нет. Элементы, для которых нет оборудования (Bluetooth, Wi-Fi на ПК с
  кабелем, яркость на мониторе ПК), скрыты, а остальные сдвигаются и закрывают
  пустое место. Сюда же попадают переключатели из «Быстрых настроек» других
  расширений, а для Caffeine есть отдельный адаптер.
- **Отдельные меню Wi-Fi и батареи.** В меню Wi-Fi отображаются доступные сети,
  текущее подключение и выключатель радио. В меню батареи — заряд, оставшееся
  время, источник питания и режимы энергопотребления.
- **Баннеры уведомлений справа**, под часами, а не по центру.
- **Внешний вид.** Панель может быть прозрачной, полупрозрачной, сплошной или
  повторять тему GNOME. При автоматическом цвете текста Lintel смотрит на обои
  под панелью и сам выбирает светлый или тёмный текст. Настраиваются высота,
  отступы, интервалы, шрифт, скругление и эффекты наведения и нажатия.
- **Панель в полноэкранном режиме.** В полноэкранном приложении подведите
  указатель к верхнему краю экрана, и панель выедет поверх окна.
- **Настройки применяются сразу.** Любое изменение в окне настроек (libadwaita)
  действует мгновенно, перезапускать расширение не нужно.
- **Языки:** английский и русский.

## Требования

- Основная цель — **GNOME Shell 50**, GNOME Shell 51 тоже поддерживается.
  Разработка и тестирование идут под Wayland.
- Необязательно, для отдельных виджетов:
  - *Погода:* службы геолокации (GeoClue) для автоматического определения места.
    Город можно указать и вручную. Прогноз берётся из сервисов без ключа
    (Open-Meteo или wttr.in), так что API-ключ не нужен.
  - *Ближайшие события / события календаря:* календари в GNOME Календаре или
    Evolution Data Server.
  - *Экранное время:* «Параметры» → «Благополучие» с включённой записью
    экранного времени.
  - *Пункт «Центр приложений»:* любое приложение, которое открывает ссылки
    `appstream://`, например GNOME Software.
  - *Плитка AirDrop:* в GNOME нет AirDrop, поэтому плитка запускает первое
    установленное приложение для обмена файлами с устройствами поблизости, в
    таком порядке: [LocalSend](https://localsend.org) (пакет дистрибутива или
    Flatpak),
    [GSConnect](https://github.com/GSConnect/gnome-shell-extension-gsconnect),
    [KDE Connect](https://kdeconnect.kde.org), затем передача файлов по
    Bluetooth из GNOME (`bluetooth-sendto`, только если есть Bluetooth-адаптер).
    Во второй строке плитки написано, какое приложение она откроет. Если ни
    одного нет, открываются «Параметры» → «Общий доступ». Ближе всего к AirDrop
    LocalSend: он работает с телефонами и компьютерами в той же сети, включая
    iPhone и Android.

## Установка

### Из релиза

1. Скачайте `lintel@topbar.shell-extension.zip` на странице
   [Releases](../../releases).
2. Установите:

   ```bash
   gnome-extensions install --force lintel@topbar.shell-extension.zip
   ```

3. Выйдите из сеанса и войдите снова. В Wayland GNOME Shell видит новые
   расширения только после входа.
4. Включите:

   ```bash
   gnome-extensions enable lintel@topbar
   ```

### Из исходников

```bash
git clone https://github.com/eliotBenitez/lintel.git
cd lintel
./install.sh          # собирает схему и переводы, создаёт симлинк в ~/.local/share/gnome-shell/extensions
```

Выйдите из сеанса, войдите снова и выполните `gnome-extensions enable lintel@topbar`.

Для `install.sh` нужны `glib-compile-schemas` и `msgfmt` (из gettext).

## Использование

| Действие | Как |
|---|---|
| Открыть Центр уведомлений | Нажать на часы или <kbd>Super</kbd>+<kbd>V</kbd> |
| Настроить виджеты | Открыть Центр уведомлений и выбрать **«Изменить виджеты»** |
| Открыть Центр управления | Нажать на значок Центра управления слева от часов |
| Открыть настройки | `gnome-extensions prefs lintel@topbar` или приложение «Расширения» |
| Показать панель в полноэкранном режиме | Подвести указатель к верхнему краю экрана |

В окне настроек четыре страницы: **«Компоновка»**, **«Часы»**, **«Погода»** и
**«Внешний вид»**. У каждой настройки есть ключ GSettings, поэтому её можно
менять из скриптов:

```bash
gsettings set org.gnome.shell.extensions.lintel appearance translucent
gsettings list-recursively org.gnome.shell.extensions.lintel
```

### Режим штатных «Быстрых настроек»

Если вам привычнее стандартное меню «Быстрых настроек» GNOME, отключите
собственный Центр управления:

```bash
gsettings set org.gnome.shell.extensions.lintel control-center-mode native
```

## Совместимость с другими расширениями

Lintel не трогает `statusArea`, `menuManager` и «Быстрые настройки» GNOME,
поэтому индикаторы других расширений остаются на своих местах. Их переключатели
из «Быстрых настроек» появляются кнопками в Центре управления. Плитки, которые
Центр управления показать не может (ползунки, нестандартные виджеты), остаются в
штатных «Быстрых настройках», и те остаются доступны, пока такие плитки есть.

## Удаление

```bash
gnome-extensions disable lintel@topbar
gnome-extensions uninstall lintel@topbar
```

Стандартная панель возвращается уже после отключения. Сбросить все настройки
Lintel можно так:

```bash
dconf reset -f /org/gnome/shell/extensions/lintel/
```

## Разработка

```bash
./install.sh                                   # симлинк рабочей копии в каталог расширений
dbus-run-session -- gnome-shell --nested --wayland   # изолированная вложенная оболочка для тестов
journalctl --user -f -o cat /usr/bin/gnome-shell     # следить за ошибками GJS
tools/check-undefined-calls.py                 # статическая проверка вызовов удалённых/необъявленных функций
tools/update-translations.sh                   # пересобрать .pot и обновить .po
tools/package.sh                               # собрать dist/lintel@topbar.shell-extension.zip
tools/capture-screenshots.sh                   # переснять воспроизводимую галерею GNOME Shell
```

GNOME Shell кэширует модули расширений, поэтому после правки `.js` обычно нужно
заново войти в сеанс (или проверять во вложенной оболочке).

Документация для разработчиков написана на английском:

- [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md): устройство, модули и правило
  «никогда не заменять `Main.panel`».
- [`docs/IMPLEMENTATION.md`](docs/IMPLEMENTATION.md): состояние каждой подсистемы
  и полный чек-лист ручного тестирования.
- [`docs/TESTING.md`](docs/TESTING.md): протокол тестирования в живом сеансе,
  включая 20 циклов включения и отключения.
- [`docs/DECISIONS.md`](docs/DECISIONS.md) и
  [`docs/PROJECT_MEMORY.md`](docs/PROJECT_MEMORY.md): архитектурные решения и
  найденные особенности GNOME Shell.
- [`AGENTS.md`](AGENTS.md): стиль кода и правила для контрибьюторов.

### Участие

Issues и pull requests приветствуются. В pull request опишите:

- что изменилось для пользователя
- на каких версиях GNOME проверяли
- результаты ручного тестирования, включая то, что после отключения панель
  по-прежнему возвращается в исходный вид

К визуальным изменениям приложите скриншоты.

### Переводы

Переводы лежат в [`po/`](po). Чтобы добавить язык, скопируйте
`po/lintel@topbar.pot` в `po/<язык>.po`, переведите его и запустите
`tools/update-translations.sh`.
